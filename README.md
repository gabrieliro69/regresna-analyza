# regresna-analyza

Interaktívna HTML stránka (v slovenčine, bez externých závislostí) na výpočet regresnej analýzy vplyvu finančnej gramotnosti na mieru úspor, zadlženosť a držbu rizikových aktív – s kontrolnými premennými vek, príjem a vzdelanie.

Stránku otvoríte jednoducho dvojklikom na súbor `regresna-analyza.html` v prehliadači; všetky výpočty prebiehajú lokálne.
